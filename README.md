# LogisTMS — лендинг для SaaS / TMS

Готовый прототип лендинга для системы управления автопарком и международными перевозками. Целевой рынок — Узбекистан.

## 📁 Структура

```
tms-landing/
├── index.html      # вся структура и тексты
├── styles.css      # дизайн (mobile-first, без зависимостей)
├── script.js       # форма, аналитика, smooth-scroll
└── README.md       # эта инструкция
```

Запуск: открыть `index.html` в браузере или через любой статический хостинг (Netlify / Vercel / GitHub Pages / Beget / hosting.uz).

## 🔌 Интеграции

### 1. Подмените контактные данные

В `index.html` найдите и замените:
- `+998901234567` — телефон / WhatsApp
- `logistms_uz` — Telegram username
- `hello@logistms.uz` — email
- `logistms.uz` — домен в meta-тегах

### 2. Аналитика

В `index.html` раскомментируйте блоки и вставьте свои ID:
- **Google Analytics 4** — `G-XXXXXXX`
- **Meta Pixel** — `XXXXXXXXX`
- **Яндекс.Метрика** — `XXXXXXXX`

### 3. CRM Webhook

В `script.js` найдите:
```js
const WEBHOOK_URL = '';
```
Вставьте ваш endpoint:
- AmoCRM: `https://yourdomain.amocrm.ru/api/v4/leads/...`
- Bitrix24: `https://yourdomain.bitrix24.ru/rest/.../crm.lead.add`
- Свой backend: `https://api.logistms.uz/webhook/lead`

Передаются: `name`, `phone`, `email`, `company`, `fleet`, `utm_*`, `page`, `timestamp`.

### 4. Цели конверсий

Уже навешаны через `data-event`:
- `cta_demo_hero`, `cta_whatsapp_hero`
- `lead_submit`, `lead_whatsapp`, `lead_telegram`
- `sticky_whatsapp`, `sticky_telegram`

## 🚀 Что дальше

### Перенос на CMS (по приоритету)

| Платформа | Когда использовать |
|-----------|-------------------|
| **Tilda** | Быстрый запуск (1–2 дня), не нужен dev. Импорт через Zero Block. |
| **Webflow** | Нужны кастомные анимации, A/B-тесты. |
| **WordPress + Elementor** | Уже есть инфраструктура / SEO-блог. |
| **Static (Netlify)** | Если будут править в коде. Самый быстрый и дешёвый. |

### Контент для production

- [ ] Заменить логотипы клиентов на реальные изображения
- [ ] Сфотографировать или купить стоковые фото водителей/автопарка
- [ ] Записать короткое видео-демо платформы (60–90 сек) для Hero
- [ ] Заменить дашборд-мокап на реальный скриншот системы

### Реклама

- [ ] Подключить Meta Pixel и проверить событие `Lead`
- [ ] Настроить Google Ads conversion (через GA4 → Import)
- [ ] Настроить Яндекс.Метрику + цели → Яндекс.Директ
- [ ] UTM-разметка для всех источников

### A/B тесты для оптимизации (когда наберётся 200+ лидов)

1. Заголовок Hero (выгода vs функция)
2. Цвет CTA-кнопки (синий vs зелёный vs оранжевый)
3. Длина формы (короткая vs расширенная по умолчанию)
4. Расположение кейсов (выше/ниже формы)

## 🎨 Рекомендации по визуалу

- **Hero-иллюстрация**: 3D-рендер грузовика + дашборд (или замените мокап на видео-loop платформы)
- **Цветовая схема**: тёмно-синий (доверие, B2B) + изумрудный акцент (выгода, экономия)
- **Шрифт**: Inter (универсальный, читаемый, поддерживает кириллицу и узбекскую латиницу)
- **Иконки**: используйте Lucide / Heroicons для единообразия
