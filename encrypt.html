🔐 Шифрование GitHub токена

Эта утилита зашифрует ваш GitHub токен паролем. Зашифрованный блок безопасно хранить в публичном коде — без пароля его нельзя расшифровать.

Шаг 1.

Создайте GitHub токен: тут (scope repo, expiration — год или больше)

Шаг 2.

Введите пароль для админки и токен ниже, нажмите «Зашифровать».

Шаг 3.

Скопируйте полученный блок и вставьте в файл admin.js (строка ENCRYPTED_TOKEN = '...'), сделайте git push.

⚠️ Важно: Запомните пароль! Без него нельзя восстановить токен. При утере — создайте новый токен и зашифруйте заново.
